# worker-manifest.txt — worker/ → guest /opt/harness bake map (phase-06).
#
# Grammar (one entry per line, '#' comments, TAB-separated fields):
#   <guest-dest-path><TAB><worker-source-path>   bake into the image
#   !<worker-source-path><TAB><reason>           host-only: never baked
#
# Every regular file under worker/ MUST be classified exactly once — either
# a bake line above or a '!' host-only line below. The drift test fails on
# unclassified, duplicate, or byte-divergent entries, so a worker change
# must update this manifest (and the baked copies) in the same PR.
#
