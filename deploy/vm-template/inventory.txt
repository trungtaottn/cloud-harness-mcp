# inventory.txt — canonical inventory contract for cloudharness-vm guests.
#
# This committed file is the SPECIFICATION, not a captured inventory: a real
# inventory only exists after a live build (phase-11 gate). inventory.sh
# inside the payload must emit every section and key listed here, in this
# order, deterministically (LC_ALL=C, sorted tabular sections). Two builds
# from identical inputs must produce byte-identical inventory output; the
# sha256 of that output is the templateDigest recorded in the build
# manifest (scripts/vm-template-build.sh build).
#
# Format: '## <section>' headers mirror `section <name>` calls in
# inventory.sh; '- <key>' bullets are scalar keys the section must emit;
# '- <rows>' marks a tabular section that must be non-empty.
